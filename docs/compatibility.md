# Codex 桌面兼容性

npm 包根目录使用当前宿主已支持的 `.codex-plugin/plugin.json` 和 `.mcp.json`。本次保持桌面兼容格式，不同时引入另一套清单发现规则。

MCP 使用 `node ./dist/server.mjs` 与 `cwd: "."`，由 Codex 将工作目录解析为实际插件根目录；不依赖源码目录、维护者绝对路径或预先计算的缓存位置。原生隔离测试使用真实 app-server 获取工具目录，不能以手动替换占位符冒充宿主加载成功。

业务配置独立保存在用户数据目录，MCP 与 Skill 共享同一配置优先级。npm 安装和插件发现不自动创建台账。缺少 Node/Python 或配置时应诊断并处理，不写入安装缓存修补命令。

更新后当前聊天可能继续持有旧工具列表或页面，需要重新启用或重开客户端。工具发现、独立 MCP 成功、构建成功均不能代表页面与附件已验收。

macOS 桌面为已使用的宿主；Linux/macOS CI 证明构建和隔离测试。Windows、其他宿主、跨客户端执行和后台常驻运行仍待验证。
