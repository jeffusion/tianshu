# Codex 桌面兼容性

当前本地插件生成 `.codex-plugin/plugin.json` 和 `.mcp.json`。不同时生成便携格式，以避免目标桌面运行时的 MCP 发现差异。此限制来自实际桌面诊断，不意味着所有未来客户端都不支持便携格式。

MCP 启动路径由 npm CLI 的安装入口生成：使用当前 Node 可执行文件、CODEX_HOME 和官方安装回执核对后的缓存位置。同步器不直接改缓存；CLI 回执路径与预期不一致时失败。运行时源码不包含维护者的个人路径。

同版本重装会更新本地文件，但当前聊天可能继续使用旧工具列表或已打开的旧页面。先重开详情页/面板；工具未刷新时完整重开桌面客户端。不要将独立 MCP 成功、清单解析成功或构建成功当作实际宿主验收。

目前 macOS Codex 桌面宿主已实际验证；Linux/macOS CI 只证明构建和隔离测试。其他宿主、Windows 安装、跨客户端执行和后台常驻运行仍待验证。
